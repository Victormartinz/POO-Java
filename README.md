# ☕ Jornada de Aprendizado: Programação Orientada a Objetos (POO) em Java

Bem-vindo(a) ao meu repositório de estudos! 🚀 Aqui vou registrar toda a minha trajetória aprendendo **Programação Orientada a Objetos (POO)** utilizando a linguagem **Java**. O objetivo é documentar minha evolução, guardar códigos de exemplo, exercícios de fixação e pequenos projetos.

## 🎯 Objetivos do Repositório
* Dominar os conceitos fundamentais do paradigma orientado a objetos.
* Praticar a sintaxe e as boas práticas de desenvolvimento em Java.
* Construir uma base sólida para a criação de sistemas modulares e reutilizáveis.
* Servir como portfólio e histórico de evolução técnica.

## 🗺️ Cronograma de Estudos

O repositório está organizado de acordo com a evolução dos meus estudos:

**Fase 1: Fundamentos Básicos**
  - Conceito de Classes e Objetos
  - Atributos e Métodos
  - Construtores e Sobrecarga
  - Palavra-chave `this`

 **Fase 2: Os 4 Pilares da POO**
  - **Encapsulamento:** Modificadores de acesso (`private`, `public`, `protected`) e Métodos Getters/Setters.
  - **Herança:** Reutilização de código através de classes e subclasses (`extends`).
  - **Polimorfismo:** Sobrescrita de métodos (`@Override`) e interfaces.
  - **Abstração:** Classes abstratas e métodos sem implementação biológica.

**Fase 3: Pequenos Projetos Práticos E Exercicios de fixação**
  - Desafios de código e pequenos sistemas de console.

## 📁 Estrutura do Projeto
